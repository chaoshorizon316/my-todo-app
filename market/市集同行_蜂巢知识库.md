# 二、产品规划

---

## 2.1 联盟大厅功能规划

### 功能定位

提供活动推广服务，增加曝光率，给用户赚钱佣金的方式。

### 核心链路

```
推广任务发布 → 用户报名 → 分享绑定（追踪） → 佣金计算 → 结算 → 钱包提现
```

### 任务状态

| 状态 | 说明 |
| --- | --- |
| 报名中 | 推广大使报名阶段 |
| 审核通过 | 审核通过，正式成为推广大使 |
| 缴费中 | 活动进行中 |
| 已结束 | 活动结束，待结算 |

### 佣金模式

| 模式 | 说明 |
| --- | --- |
| 固定金额 | 每个有效用户固定佣金 |
| 比例佣金 | 按用户消费金额的比例计算 |

### 待实现功能

- [ ] 分享绑定机制（URL参数/本地存储）
- [ ] 推广素材库（海报、文案模板）
- [ ] 推广排行榜
- [ ] 消息通知（有人通过链接报名/缴费）
- [ ] 多级邀请奖励

---

## 2.2 会员权益体系

### 三大权益模块

| 模块 | 权益内容 |
| --- | --- |
| **会员优先权** | 免费活动优先报名（24h预热）、报名费免费、押金9折、佣金减免2%、入场费9.5折 |
| **全程保障** | 实时通知（报名/审核/入选/落选）、落选优先递补、纠纷协调 |
| **认证会员标识** | 主页标识、平台工具免费用、积分体系（100积分=1元） |

### 权益亮点

- 实时通知解决了用户"报名后不知道结果"的痛点
- 积分抵扣会员费，形成留存闭环
- 落选优先递补，给了未被选中的用户一个希望

## 3.1 街子古镇雅韵生活市集摊主租赁协议

**位置**：街子古镇内朝阳路区域

### 协议框架

| 章节 | 内容 |
| --- | --- |
| 一、租赁信息 | 摊位位置、面积、经营品类、租赁期限 |
| 二、租金与押金 | 两种租金模式、押金标准与退还 |
| 三、双方权利与义务 | 甲方权利义务、乙方权利义务 |
| 四、违约责任 | 各类违约情形及违约金标准 |
| 五、其他条款 | 不可抗力、争议解决、生效条款 |

### 两种租金模式

| 模式 | 说明 |
| --- | --- |
| 模式一 | 固定租金 + 营业额抽成（按每日营业额%计算，次日结清） |
| 模式二 | 纯营业额抽成（无固定摊位租金） |

### 押金标准

- 每个摊位押金：**1000元**
- 退还条件：活动结束后3个工作日内，摊位验收合格后无息退还

### ⚠️ 重要条款提醒

#### 垃圾处理规定（合同必含）

> 乙方经营期间产生的垃圾，须打包不散落不流漏放置在景区垃圾桶旁，不能直接倾倒。

**违规处理**：
- 如引起景区投诉，乙方须按景区要求缴纳罚款
- **最低不低于 200元/次**
- 乙方负责恢复该环境的卫生情况

**建议补充条款**：
> 乙方自备垃圾袋收集垃圾，摊位区域内不得摆放垃圾桶供顾客使用。

#### 法定节假日出摊要求

| 要求 | 说明 |
| --- | --- |
| 出摊时间 | 11:00-20:00（可提前30分钟到场准备、延迟30分钟收摊） |
| 特殊天气 | 可协商灵活调整 |
| 违约罚款 | 每次200元，累计3次及以上可解除协议 |

### 附件清单

- [ ] 身份证
- [ ] 营业执照（餐饮）
- [ ] 食品相关许可证（餐饮）
- [ ] 健康证（集市活动期间有效期内）

## 4.1 营收模式

### 收入来源

| 来源 | 模式 |
| --- | --- |
| 摊主租金 | 固定租金 或 营业额抽成 |
| 场地方分成 | 按场地方收益比例分成 |

| 推广佣金 | CPS分销模式 |

### 招商策略

- 平台数据每周更新展示
- 合作方加入可联名减费用
- 先内部发布，再对外发布（增加紧迫感）

---

## 4.2 推广大使招募方案

### 活动目标

| 指标 | 目标 |
| --- | --- |
| 参与人数 | ≤200人 |
| 总预算 | ≤1,000元/天 |
| 平台 | 小红书 + 微信朋友圈 |

### 推广方案

| 平台 | 内容要求 | 核验方式 | 单价 |
| --- | --- | --- | --- |
| 小红书 | 指定文案 + 带平台二维码 | @平台主账号 + 截图提交 | 4-5元/条 |
| 微信朋友圈 | 指定文案 + 带平台二维码 | 集赞≥20-30 + 截图提交 | 2-3元/条 |

### 防羊毛机制

| 限制条件 | 说明 |
| --- | --- |
| 人数上限 | 先到先得，满额自动截止 |
| 集赞门槛 | 朋友圈≥20-30赞，防止无效发布 |
| 保留时间 | 内容发布后保留≥48小时 |
| 每人限参与 | 同一账号仅计一次 |
| 截图时效 | 发布后2小时内必须提交 |
| 审核复查 | 48小时后复查，删帖不结算 |

### 素材包内容

- [ ] 小红书文案（2-3条备选）
- [ ] 朋友圈文案（短文案，便于截图）
- [ ] 二维码图片（平台群聊/小程序码）
- [ ] 参考示例（1-2个优秀案例）
