## 四、体验版测试

### 4.1 测试 Checklist
- [ ] 启动小程序，引导页正常显示 → 完成引导跳转心湖
- [ ] 心湖页：湖面动画正常，可「投一颗石子」记录情绪
- [ ] 涟漪页：情绪分布图 + 时间线正常加载

- [ ] 退出重进，登录态保持
- [ ] 切换飞行模式 → 验证错误提示友好

### 4.2 常见问题
- **callContainer 调用失败**：确认云开发环境 ID 正确，确认小程序已关联云开发
- **登录失败**：确认微信云托管服务正常运行
- **页面白屏**：检查控制台错误，确认 `wx.cloud.init()` 已执行

## 五、提交审核

1. 管理后台 → **版本管理** → 选为体验版 → 测试通过后点「提交审核」
2. 服务类目建议：**社交 > 笔记** 或 **工具 > 信息查询**
3. 上传首页截图（心湖页）
4. 审核备注可选填测试账号信息

## 六、审核通过 → 发布

1. 审核通过后在版本管理中「提交发布」
2. 建议分阶段发布（先 5%，无异常后全量）
3. 发布后 1-2 小时内生效
