### 2.1 配置服务器域名
1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 导航：**开发** → **开发管理** → **开发设置** → **服务器域名**
3. 在 **request 合法域名** 中添加：
   ```
   https://express-cd9z-258058-4-1433329054.sh.run.tcloudbase.com
   ```
4. 点击保存，扫码验证身份
5. **取消勾选**「不校验合法域名」（开发者工具 → 详情 → 本地设置）

### 2.2 注意事项
- request 合法域名每月仅可修改 5 次
- 域名必须以 `https://` 开头
- 不支持 IP 地址和端口号

## 四、体验版测试

2. 在「开发版本」中找到刚上传的版本
3. 点击「选为体验版」
4. 添加体验成员（需已关注该小程序）

### 4.2 体验版测试 Checklist

## 五、提交审核

### 5.1 提交步骤
1. 管理后台 → **版本管理** → 体验版 → 点击「提交审核」
2. 填写审核信息：
   - **服务类目**：建议选择「工具 > 信息查询」或「社交 > 日记/笔记」
   - **标签**：心情记录、情感陪伴、心灵守护
3. 上传小程序截图（至少一张首页截图）
4. 提交后等待微信审核（通常 1-7 个工作日）

### 5.2 审核被拒常见原因
- **功能不完整**：所有 Tab 页面必须有内容，不能是空白占位
- **缺少隐私协议**：需在「设置 > 基本设置 > 服务内容声明」中填写隐私保护指引
- **类目不符**：选择与实际功能匹配的类目
- **域名未配置**：request 合法域名必须包含所有后端接口域名
- **强制登录**：未登录状态下也应能浏览部分内容
- **测试账号**：建议在审核备注中提供测试账号信息

## 六、审核通过 → 发布

1. 审核通过后，在「版本管理」中点击「提交发布」
2. 建议设置**分阶段发布**（如先 5% 用户，观察无异常后全量）
3. 发布后约 1-2 小时内全量生效
